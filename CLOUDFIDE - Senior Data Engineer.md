- 4+ years of hands-on experience as a Data Engineer or in a closely related engineering role.
- 2+ years experience working with cloud platforms (Azure-first; AWS/GCP experience also valuable).
- Strong Python skills — ability to write maintainable, production-ready code in distributed data environments.
- Advanced SQL proficiency and experience with relational databases (SQL Server, PostgreSQL, etc.).
- Expertise in DWH data modeling, ETL/ELT architectures, and modern data design patterns (Lakehouse preferred).
